# mbatt-astro.github.io

Personal research site — plain HTML, no build step.

## Publish (about 5 minutes)

1. On GitHub, create a new **public** repository named exactly `mbatt-astro.github.io`.
2. Click **Add file → Upload files** and drop in `index.html` and `README.md`. Commit.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`. Save.
4. After a minute or two the site is live at https://mbatt-astro.github.io

## Editing

Everything lives in `index.html`. To update:
- **Talks/posters:** copy the commented `<li>` template in the Publications section.
- **Further reading:** add `<li>` entries under the relevant group.
- **Contact:** replace `YOUR-EMAIL-HERE` and `YOUR-ORCID`.

Edit straight on GitHub (pencil icon) — changes go live within a minute.
